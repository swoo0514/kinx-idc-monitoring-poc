# 설계 근거 — 왜 이렇게 만들었나

무엇을 만들었는지는 각 디렉토리의 가이드에 있습니다. 여기는 **왜 그렇게 골랐는지**입니다.

## 판정 인덱스

| 무엇을 정했나 | 결론 | 근거 |
|---|---|---|
| 세 시스템의 심각도를 어떻게 합칠 것인가 | 통합 눈금 SEV1~4 + NONE. **사내 Warning은 SEV4, MSP Warning은 SEV3** | [severity-normalization.md](severity-normalization.md) |
| 외부 LLM에 무엇을 보낼 것인가 | 단일 반출구 + 화이트리스트 + 가역 마스킹 | [llm-data-contract.md](llm-data-contract.md) |
| 무엇을 규칙이 정하고 무엇을 LLM이 하나 | **판정은 코드, 설명만 LLM** | [rules-inventory.md](rules-inventory.md) |
| 주장의 출처를 어떻게 표기하나 | `[문서]` / `[코드]` / `[제안]` 3분 | [evidence-policy.md](evidence-policy.md) |
| 알림 저장·UI·승인을 만들 것인가 살 것인가 | **Keep 채택** — 단 게이트웨이가 먹여주는 방식 | [ADR-001](decisions/adr-001-keep-adopt.md) |
| 선도 OSS 원인분석 도구를 도입할 것인가 | **하이브리드** — 실시간·MSP는 자체 봇, 심층은 에이전틱 | [ADR-002](decisions/adr-002-holmesgpt.md) |
| 왜 사지 않고 만들었나 | PoC 단계에서는 자체 제작. **단 유지할 제품이 아님** | [ADR-003](decisions/adr-003-build-vs-buy.md) |
| 네트워크 계층 관측을 추가할 것인가 | **1순위는 Suricata가 아니라 dnsdist 네이티브 관측을 켜는 것** | [ADR-004](decisions/adr-004-suricata-defer.md) |
| LLM 경로를 어떻게 잡을 것인가 | Claude 주 경로 + Ollama 폴백 + **열화 모드**. 재시도 없음 | [ADR-005](decisions/adr-005-llm-path.md) |

## 이 판정들을 관통하는 것

**① 판정은 코드, 설명은 LLM.**
병합 규칙과 만성/신규 판정은 결정적입니다. 같은 입력이면 몇 번을 돌려도 같은 답이 나옵니다.
LLM은 이미 정해진 사건에 **인과를 설명**할 뿐 판정을 뒤집지 않습니다. 환각을 통제하는 방법이
"LLM에게 조심하라고 시키는 것"이 아니라 **구조적으로 판정 권한을 안 주는 것**입니다.

**② 도구를 고를 때는 하드 요건에 걸어 채점한다.**
Keep도 HolmesGPT도 문서 논쟁으로 정하지 않고 **같은 랩·같은 시나리오에 걸어 실측**했습니다.
그 결과 하나는 채택, 하나는 하이브리드가 됐습니다. **어느 쪽이든 실측 근거로 고른 것이
산출물의 가치**입니다.

**③ 가정은 조사로 깬다.**
착수 가정이 공식 문서 한 번으로 뒤집힌 사례가 여러 번 있었습니다
([evidence-policy](evidence-policy.md) 참조). 그래서 근거 표기 규약을 두고, 무너진 가정도
기록으로 남깁니다 — **정정 자체가 산출물**입니다.

**④ 있는 것을 켜서 잇는다.**
무거운 substrate(Zabbix의 예측 함수, Keep의 저장·워크플로)는 성숙한 OSS에 위임하고,
**지능(정규화·병합·만성 판정)만 우리 얇은 층에 둡니다.** 커스텀 봇을 키우지 않는 것이
도입 설득 논리와도 일치합니다.

## 무엇을 안 하기로 했나

안 하기로 한 것도 판정입니다.

- **룰 없는 이상 탐지** — 기각. 환각 위험이 "코드 선판정" 원칙과 충돌합니다.
- **별도 GUI 워크플로 엔진 추가** — 안 함. Keep의 승인 계층을 두 번 재사용했습니다(조치·리포트).
- **Suricata 랩 구축** — 안 함. 정당성이 좁혀졌고 더 싼 선택지가 먼저입니다.
- **Active Response·외부 해시 전송(VirusTotal 등)** — 제외. 계약 제약과 반출 원칙에 걸립니다.
- **컨테이너·클라우드 커넥터** — 제외. 대상이 없습니다.
