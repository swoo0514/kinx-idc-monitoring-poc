## 알려진 미해결 (설계 갭)

상세는 [`../03-pitfalls/structural-gaps.md`](../03-pitfalls/structural-gaps.md).

- **만성 판정 횟수가 200에서 포화**(G3) — 판정 자체는 안전하나 **랭킹이 무의미해집니다**
- **병합 키에 호스트명 정규화 미적용**(G4) — 이름이 다르면 같은 호스트도 별개 사건
- **LLM 호출 동시성 상한 없음**(G7) — **랩에서는 재현 불가, 실환경에서만 터짐**
- **재기동 시 열린 인시던트 유실**(G8) — 자동 재기동이 유실을 조용하게 만듦
- **분류기가 아이템 키를 안 씀**(G2b) — 미디어타입 파라미터 추가 + 랩 재배선 필요

## 미확인으로 남은 것

**"확인 안 했다"와 "없다"를 구분합니다.**

- `countOutput`으로 정확한 개수를 얻을 수 있는지 — 공식 문서 미확인
- Ollama 폴백의 실제 지연 — 미측정. 예산을 넘으면 "온프렘은 사양 상향 필요"를 정직하게 적습니다
- LLM 모델 선정 — opus vs sonnet 지연·비용·품질 비교 미실시
- LLM 응답 보존(retention) 정책 — 학습 불가는 계약으로 확정, **보존 기간은 미확정**
- 실환경 에이전트 배포율
