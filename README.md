# kinx-idc-monitoring-poc

KINX 서비스운영팀 IDC 파트의 모니터링 시스템(Zabbix + Grafana/Alloy + Wazuh) 고도화 3주 PoC입니다. 실환경 진단을 근거로 통합 관제·자동 조치·AI 초동 분석을 재현 가능한 데모로 검증하고, 실환경 도입 로드맵을 산출합니다. 실환경에는 변경을 가하지 않으며, 별도의 미러 랩에서 검증합니다.

> 본 저장소는 재현 가능한 코드(랩 구성·대시보드·자동화·봇)를 공개 범위로 관리합니다. 실환경 정찰 결과·전략 문서·크리덴셜 등 민감 정보는 비공개(private)로 분리하며 커밋하지 않습니다.

## 저장소 구성

| 디렉토리 | 내용 | 상태 |
| --- | --- | --- |
| `lab/` | Docker 관측 코어 (Zabbix·MariaDB·Grafana·Loki) 및 랩 구성 | 구축 중 |
| `tools/` | 실환경 정찰용 읽기 전용 스크립트 (Zabbix 스냅샷·통계) | 완료 |
| `dashboards/` | Grafana 대시보드 정의 (JSON provisioning) | 예정 |
| `ansible/` | 자동 조치 플레이북 (자가 치유) | 예정 |
| `bot/` | LLM 트리아지 봇 (AI 초동 분석) | 예정 |
| `chaos/` | 장애 주입 스크립트 | 예정 |
| `demo/` | 데모 시나리오 대본 | 예정 |

## 데모 구성 (계획)

- **데모 A — 통합 관제:** 메트릭·로그·보안을 Grafana 단일 화면에서 관측하고, 알림 노이즈를 정비합니다.
- **데모 B — 자가 치유:** 웹훅 → 승인(Human-in-the-loop) → Ansible 자동 조치.
- **데모 C — AI 초동 분석:** 알림 발생 시 LLM이 원인·확인 명령을 즉시 회신합니다.

## 시작하기

각 구성 요소의 구축 방법은 해당 디렉토리의 README를 참조합니다. 관측 코어는 [`lab/README.md`](lab/README.md)에서 시작합니다.

전략 문서·실행 계획·실환경 진단 결과는 내부 문서(비공개)로 관리합니다.
